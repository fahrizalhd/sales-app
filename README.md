# Sales App

Sales App is a web application designed to help businesses manage their sales processes efficiently. Built with Laravel, it offers a modern, intuitive interface for tracking leads, managing customers, and analyzing sales performance.

## Features

- Lead and customer management
- Sales tracking and reporting
- Product and inventory management
- User roles and permissions
- Secure authentication
- Responsive dashboard

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/sales-app.git
   ```
2. Install dependencies:
   ```
   composer install
   npm install
   ```
3. Set up your `.env` file and database.
4. Run migrations:
   ```
   php artisan migrate
   ```
5. Start the development server:
   ```
   php artisan serve
   ```
